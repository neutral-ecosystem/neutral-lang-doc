# Neutral API documentation website

This `doc-website/` directory is the tracked static API documentation site for Neutral. It is
generated by `cargo xtask docs` from workspace Rustdoc, Cargo metadata, and the
site templates owned by `xtask`.

`index.html` is the hostable entry point. It introduces the language
capabilities, groups the workspace crates by role, and links to each generated
crate API. The `.nojekyll` marker keeps static-hosting platforms from filtering
Rustdoc paths.

Do not edit files in this directory by hand. Make documentation, package
metadata, or site-template changes in their owning source, then run:

```sh
cargo xtask docs
```

The command refreshes this tracked site and the disposable local copy at
`target/doc/`. A static host can publish `doc-website/` directly without
requiring a Rust toolchain at serving time. CI regenerates the site to validate
the generator. Commit intentional refreshes from the selected stable toolchain;
Rustdoc assets can differ across stable compiler releases.
